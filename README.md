# Digital Clock (Verilog HDL)

基于 Verilog HDL 的数字时钟系统，6位数码管显示 时:分:秒

## 项目简介

使用 Verilog HDL 实现的 24 小时制数字时钟，支持 6 位动态数码管显示，具备复位功能。

## 功能特性

- 24小时制计时（00:00:00 ~ 23:59:59）
- 6位数码管动态扫描显示
- BCD码时分秒独立计数
- 异步复位，上电归零

## 模块结构

```
clock_top.v       顶层模块
├── time_counter.v    时分秒 BCD 计数器
├── scan_ctrl6.v      6位数码管扫描控制
└── seg_decoder.v     七段译码（共阳）
tb_clock.v        仿真测试文件
```

## 开发环境

- 语言：Verilog HDL
- 工具：Vivado / ISE
- 仿真：功能仿真 + 波形验证
- 时钟：50MHz

## 设计说明

- 1秒计数器：50MHz × 1s = 50,000,000 个时钟周期
- 扫描频率：1kHz（每位约1ms刷新，视觉无闪烁）
- 进位逻辑：秒→分→时，满60/24自动归零
